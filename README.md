# DS 3000 / ECE 9611: Introduction to Machine Learning

Code demos for the course at Western University. Each demo is in its own folder with its own README and setup instructions.

| Demo | What it shows |
|---|---|
| [face-detection-demo](face-detection-demo) | Live face detection on your laptop camera: a classic Haar cascade and the YuNet CNN, with step-by-step walkthroughs of how each one finds a face |
| [clustering-demo](clustering-demo) | K-means, GMM and agglomerative clustering on the same data, evaluated with the silhouette score, plus the elbow method and a dendrogram for choosing K |
| [transfer-learning-demo](transfer-learning-demo) | Transfer learning with ResNet50, MobileNetV2 and EfficientNetB0 on a small flower dataset: frozen feature extraction, freezing a network, and fine-tuning |

## Getting the code

With git:

```
git clone https://github.com/AiX-Lab-UWO/DS3000-ECE9611.git
```

Without git: click the green **Code** button on this page, choose **Download ZIP**, and unzip it.

Then open the folder of the demo you want and follow its README.
